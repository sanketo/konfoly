# Konfoly

Веб-каталог сериалов с поиском, просмотром, выбором озвучки и локальной
историей. [Исходники беты](https://github.com/sanketo/konfoly/tree/beta)
собираются в [репозиторий публикации](https://github.com/sanketo/konfoly-beta)
и доступны на [GitHub Pages](https://sanketo.github.io/konfoly-beta/).
Релиз ведётся в ветке `main` репозитория исходников.

## Запуск

Требуются Node.js 22+ и npm. Сборка создаёт готовый статический сайт в `dist/`.
Имена скриптов и стилей содержат хеш содержимого.

```sh
npm ci
npm test
npm run build
python3 -m http.server 8427 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8427. Для публикации беты запустите тесты и сборку
из ветки `beta`, перенесите содержимое `dist/` в корень ветки `main`
репозитория `sanketo/konfoly-beta`, удалите устаревшие файлы сборки и отправьте
коммит. В настройках Pages репозитория публикации задайте `main / (root)`.

## Исходники и интеграции

- `app.js`, `series-library.js` и `series-metadata.js` отвечают за экраны,
  каталог и метаданные. Исключения для нумерации эпизодов и отображения
  названий находятся в `series-config.js` и `series-data.js`.
- `providers.js` подключает видео. `series-config.js` содержит ID Менталиста,
  правило объединённых серий 3×23–24 для ТВ3, скрываемое название 6×8 и
  порядок эпизодов «Интернов» для видеопровайдера.
- Каталог сохраняет сведения о добавленных сериалах в браузере. Если браузер
  запрещает запись, каталог доступен до закрытия вкладки.

Поиск обращается к TVmaze, Wikidata и Cinemeta. Списки эпизодов кэшируются в
браузере. Если TVmaze и Cinemeta задерживают ответ, каталог сверяет ID сериала
с Wikidata и загружает таблицы эпизодов из Википедии по сезонам. Подключение
источников видео описано ниже.

### Видеопровайдеры и CSP

`integrations.js` задаёт источники для плеера и домены для CSP. После изменений
пересоберите и опубликуйте бета-сайт. Указывайте публичные HTTPS-адреса.
Ключи и токены оставляйте на стороне сервиса, который отдаёт видео.

| Настройка | Что указать |
| --- | --- |
| `episodeEndpoint`, `stremioManifest` | Адрес общего API и `manifest.json` дополнения. Они автоматически попадают в `connect-src`. |
| `mediaOrigins` | Домены MP4, плейлистов HLS, сегментов, ключей и перенаправлений. Они разрешаются в `media-src` и `connect-src`. |
| `embeds`, `embedOrigins` | Проверенные адреса iframe, включая Namy и Alloha, и дополнительные домены iframe, возвращаемых общим API. |
| `seriesSources` | Объект по ID сериала (`mentalist`, `tvmaze-…`) с полями `video`, `alloha` или `manifest`. Адреса добавляются в соответствующую директиву автоматически. |
| `connectOrigins`, `imageOrigins` | Дополнительные домены запросов и изображений. |

API и HLS, которые загружаются через JavaScript, должны отвечать с CORS для
домена Pages. iframe должен разрешать встраивание на странице Konfoly. Для
локальной проверки произвольных адресов можно отдать исходники командой
`python3 -m http.server 8427 --bind 127.0.0.1` из корня репозитория. Для
проверки CSP используйте `dist/`.

Telegram SDK загружается при запуске Mini App. CSP разрешает путь SDK на
`telegram.org`. SRI не настроен, поэтому выполнение кода по этому адресу
зависит от содержимого, которое отдаёт Telegram.
