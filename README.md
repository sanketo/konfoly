# Konfoly

Веб-каталог сериалов с поиском, просмотром, выбором озвучки и локальной
историей. [Бета](https://sanketo.github.io/konfoly-beta/) собирается из ветки
`beta`. Релиз публикуется отдельно из `main`.

## Запуск

Требуются Node.js 22+ и npm. Сборка создаёт готовый статический сайт в `dist/`.
Имена скриптов и стилей содержат хеш содержимого.

```sh
npm ci
npm test
npm run build
python3 -m http.server 8427 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8427. Для GitHub Pages опубликуйте содержимое
`dist/` в корне репозитория, из которого обслуживается бета.

## Исходники и интеграции

- `app.js`, `series-library.js` и `series-metadata.js` отвечают за экраны,
  каталог и метаданные. Исключения для нумерации эпизодов и отображения
  названий находятся в `series-config.js` и `series-data.js`.
- `providers.js` подключает видео. Адреса провайдеров, параметры Namy и
  разрешённые домены задаются в `integrations.js`. Сборка использует этот файл
  для формирования Content Security Policy. Добавляйте домены API, видео, изображений и
  iframe в соответствующие списки. Ключи API храните на сервере.
- Каталог сохраняет сведения о добавленных сериалах в браузере. При первом
  открытии сериала в каждой вкладке список эпизодов загружается из TVmaze.
  Если браузер запрещает запись, каталог доступен до закрытия вкладки.
