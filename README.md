# Konfoly

Веб-каталог сериалов с поиском, просмотром, выбором озвучки и локальной
историей. [Исходники беты](https://github.com/sanketo/konfoly/tree/beta)
собираются в [репозиторий публикации](https://github.com/sanketo/konfoly-beta)
и доступны на [GitHub Pages](https://sanketo.github.io/konfoly-beta/).
Релиз ведётся в ветке `main` репозитория исходников.

## Запуск

Требуются Node.js 22+ и npm. Сборка создаёт готовый статический сайт в `dist/`.
Имена скриптов и стилей содержат хеш содержимого.
Сериалы, сезоны и эпизоды открываются в одном приложении. Ссылка вида
`?series=mentalist&season=4&episode=11` передаёт выбранную серию плееру.
Карта сайта в `dist/sitemap.xml` указывает на главную страницу каталога.

```sh
npm ci
npm test
npm run build
python3 -m http.server 8427 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8427. Для публикации беты запустите тесты и сборку
из ветки `beta`, перенесите содержимое `dist/` в корень ветки `main`
репозитория `sanketo/konfoly-beta`, удалите устаревшие файлы сборки и отправьте
коммит. В настройках Pages репозитория публикации задайте `main / (root)`.

## Исходники и интеграции

- `app.js`, `series-library.js` и `series-metadata.js` отвечают за экраны,
  каталог и метаданные. Исключения для нумерации эпизодов и отображения
  названий находятся в `series-config.js` и `series-data.js`.
- `providers.js` подключает видео. `series-config.js` содержит ID Менталиста,
  правило объединённых серий 3×23–24 для ТВ3, скрываемое название 6×8 и
  порядок эпизодов «Интернов» для видеопровайдера.
- Каталог сохраняет сведения о добавленных сериалах в браузере. Если браузер
  запрещает запись, каталог доступен до закрытия вкладки.

Поиск обращается к TVmaze, Wikidata и Cinemeta. Списки эпизодов кэшируются в
браузере. При задержке полного списка приложение получает номера сезонов
из TVmaze или из таблиц Википедии, сверенных по ID сериала в Wikidata.
Выбранный сезон можно загрузить отдельно. Подключение источников видео
описано ниже.

### Синхронизация каталога

`npm run sync:catalog` обновляет `data/popular-series.json` из каталога
[Cinemeta Popular](https://v3-cinemeta.strem.io/catalog/series/top.json).
При наличии `TMDB_READ_TOKEN` команда использует TMDB Discover с сортировкой
по популярности. Токен нужен только скрипту. Сохраняются 250 уникальных
сериалов, прошедших жанровые фильтры. Если у Cinemeta есть только выборка
эпизодов, её размер не используется как общее число серий. Оригинальные
названия берутся из источника, Wikidata или редакционных данных.
Записи из общего каталога доступны через поиск. На главной отображаются
сериалы, добавленные или открытые пользователем.

Для повтора по сохранённым исходным страницам используйте
`npm run sync:catalog -- --cinemeta-pages /path/to/pages`. Имена файлов
`0.json`, `6.json`, `12.json` и дальше обозначают смещение в Cinemeta.
Файл содержит ответ с `metas` или массив исходных записей.

Для проверки воспроизведения у записи в `integrationSettings.seriesSources`
должно быть поле `authorization` со ссылкой или ссылочным номером разрешения
правообладателя. Скрипт проверяет `video` и `manifest` в пределах разрешённых
доменов CSP. Для JSON-манифеста используйте ключи вида `1:2` в объекте
`episodes`. Подтверждённый второй вариант становится резервным в плеере.
`--probe-limit` задаёт максимум проверок эпизодов на сериал, по умолчанию 12.
`--site` задаёт origin для проверки CORS. Подтверждение означает проверку
формата и начальных данных MP4, WebM или незашифрованного HLS. При неполной
проверке сериал остаётся в статусе `PARTIAL` или `UNVERIFIED`.

Для конкретного эпизода с официальным разрешённым встраиванием YouTube
можно задать `officialEpisodes` с ID видео, точным названием публикации,
адресом канала правообладателя и датой браузерной проверки. Синхронизация
сверяет публичный oEmbed. Ответ oEmbed сам по себе не заменяет проверку
начала воспроизведения. Для повторной сборки принятых ответов доступны
`--wikidata-pages` и `--oembed-dir`.
Встроенный плеер использует прямое видео из настроенных источников.
Официальный YouTube доступен отдельной кнопкой в списке источников.

### Яндекс Метрика

Основная версия и бета используют счётчик `114391998`. Для сборки беты с
другим счётчиком передайте его номер.

```sh
KONFOLY_METRICA_ID=12345678 npm run build
```

Для целей типа «JavaScript-событие» используйте `search_results`,
`search_empty`, `search_error`, `season_load_success` и `season_load_error`.
В настройки счётчика добавьте домен соответствующего сайта. Просмотры
сгруппированы по экранам. События целей содержат название цели.
Вебвизор и карты включены. Поля поиска и ввода, настройки
источников и область плеера скрыты в записи Вебвизора.
Для локальной сборки без Метрики укажите `KONFOLY_METRICA_ID=0`.

### Видеопровайдеры и CSP

`integrations.js` задаёт источники для плеера и домены для CSP. После изменений
пересоберите и опубликуйте бета-сайт. Указывайте публичные HTTPS-адреса.
Ключи и токены оставляйте на стороне сервиса, который отдаёт видео.

| Настройка | Что указать |
| --- | --- |
| `episodeEndpoint`, `stremioManifest` | Адрес общего API и `manifest.json` дополнения. Они автоматически попадают в `connect-src`. |
| `mediaOrigins` | Домены MP4, плейлистов HLS, сегментов, ключей и перенаправлений. Они разрешаются в `media-src` и `connect-src`. |
| `embeds`, `embedOrigins` | Проверенные адреса iframe, включая Namy и Alloha, и дополнительные домены iframe, возвращаемых общим API. |
| `seriesSources` | Объект по ID сериала (`mentalist`, `tvmaze-…`) с полями `video`, `alloha` или `manifest`. Адреса добавляются в соответствующую директиву автоматически. |
| `connectOrigins`, `imageOrigins` | Дополнительные домены запросов и изображений. |

API и HLS, которые загружаются через JavaScript, должны отвечать с CORS для
домена Pages. iframe должен разрешать встраивание на странице Konfoly. Для
локальной проверки произвольных адресов можно отдать исходники командой
`python3 -m http.server 8427 --bind 127.0.0.1` из корня репозитория. Для
проверки CSP используйте `dist/`.

Telegram SDK загружается при запуске Mini App. CSP разрешает путь SDK на
`telegram.org`. SRI не настроен, поэтому выполнение кода по этому адресу
зависит от содержимого, которое отдаёт Telegram.
